# iOS 27 Inspired Launcher
Android launcher source project inspired by iOS-style visuals.

- Android Gradle Plugin 8.7.3, Kotlin 2.0.21, compileSdk 35, minSdk 26.
- Home screen with clock, decorative widget cards, app shortcuts, dock and settings shortcuts.
- Lock screen is an in-app preview only; Android's actual lock screen and PIN/biometrics remain unchanged.
- Weather/calendar cards are placeholders, not live widgets.
- Build using GitHub Actions workflow at .github/workflows/build.yml.
